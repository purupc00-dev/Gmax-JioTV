**Zero footprint, immense streaming capability.** Run enterprise-grade OTT streams and bypass heavy CDN firewalls on consumer browsers. Gmax-JioTV treats raw M3U playlists, ClearKey DRM, and proxy routing as a single, invisible backend hierarchy, delivering a flawless, Netflix-tier user interface. It supports advanced live stream manipulation — **instant playback, anti-drift watchdogs, and dynamic server switching** — in pure JavaScript with zero frontend proxy dependencies, keeping your architecture entirely hidden from the browser's DevTools. [Full feature roster ↓](#✨-key-features) > Gmax-JioTV is an open-source research platform and a flagship web player you can run today. Its primary goal is to pursue streaming-side performance across the entire network/browser boundary — DRM configurations, edge routing, codec fallbacks, and live-edge snapping — so complex playlists depend less on external apps and cost less to run. --- ## ✨ Key Features ### 🛡️ Enterprise-Grade Security Architecture * **Invisible Edge Gateway:** Powered by edge workers acting as an invisible middleman that spoofs `Origin`, `Referer`, and `User-Agent` headers. * **Token Injection:** Dynamically extracts and injects `__hdnea__` and `hdntl` tokens into the `Cookie` header server-side without over-decoding URL entities. * **Private Payload Streaming:** Fetches raw M3Us from private repositories. DevTools only sees the local edge endpoint, keeping source URLs strictly confidential. ### ⚡ Master Playback Engine (Shaka Player) * **Instant Playback:** Optimized buffer configurations (`bufferingGoal: 10`, `defaultPresentationDelay: 3`) to eliminate legacy 6-8 second loading delays. * **Remote Key Pre-Fetch (Error 6001/6012 Fix):** Silently intercepts `key.php` requests, fetches Hex/JWK keys via proxy, and injects them as offline ClearKeys before playback starts. * **H.265 (HEVC) Bypass:** Forces standard H.264 playback on desktop environments to prevent browser-level codec crashes. * **Stream Watchdogs:** * **Anti-Drift:** Automatically snaps the player to the live edge if the stream lags > 25 seconds. * **Anti-Freeze:** Detects stalled frames and silently cache-busts the manifest to reload without breaking the player. ### 🎨 Premium UI/UX * **Single-Frame Hero Banner:** A dynamic, swipeable cinematic carousel powered remotely via `highlights.json`. * **True Deduplication (Server Switcher):** Merges overlapping channels from different M3U files into a single UI card. Provides an in-player Server Switcher for instant fallbacks without cross-contaminating cache. * **Live EPG Guide:** A fully functional, horizontally scrolling TV Guide mapped via `tvg-id`. * **Custom Player Controls:** Features Picture-in-Picture (PiP), Aspect Ratio toggles (Fit/Fill/Zoom), quality/audio track selectors, and a custom **Voice Boost** tool. --- ## ⌨️ Keyboard Shortcuts | Key | Action | | :--- | :--- | | `Space` | Play / Pause | | `F` | Toggle Fullscreen | | `P` | Toggle Picture-in-Picture | | `I` | Open Settings Menu | | `← / →` | Seek backward / forward 10s | --- ## ⭐ Star History See how the project has grown over time. https://star-history.com/#your-username/Gmax-JioTV&Date"> https://api.star-history.com/svg?repos=your-username/Gmax-JioTV&type=Date&theme=dark" /> https://api.star-history.com/svg?repos=your-username/Gmax-JioTV&type=Date" /> https://api.star-history.com/svg?repos=your-username/Gmax-JioTV&type=Date" /> --- ## ⚠️ Disclaimer This repository is provided for educational and research purposes only.
